## The work behind the pixels

I build software that takes a complicated process and makes it useful, reliable and understandable. My work spans **full-stack development**, **automation**, **desktop tools** and **enterprise integrations**, with a particular interest in identity and access workflows.

Based in Curitiba, Brazil. Working with Python, Java, C#/.NET, web technologies and the infrastructure that connects them.

| 01 · Build | 02 · Automate | 03 · Connect |
| :--- | :--- | :--- |
| Clear interfaces and maintainable services. | Tools that remove repetitive work. | APIs, events and identity systems that work together. |
